# Omniview 需求规格

## 定位

跨平台 **操作系统资源查看与管理** 工具（GPUI）：进程、端口、文件占用、DNS、代理相关系统状态等，帮助快速定位「谁占用了什么」以及代理使用/退出后的残留问题。

- **设计**：跨平台抽象，可扩展
- **当前实现**：仅 Windows
- **后续**：macOS / Linux 实现同一套 `platform` trait

## 非目标（现阶段）

完整资源管理器、抓包改包、防火墙策略编辑、代理客户端本身（订阅/分流规则）、远程多机。

## 产品结构

```
进程 | 端口 | 文件 | DNS | 代理排障
```

各入口可联动到共用的 **进程详情**（结束进程等）。

## 核心模型

```
Process          进程与子进程、CPU/内存、关联网络与文件
Port / Socket    本机连接与监听（一等资源）
File handle      文件/目录占用
DnsCache         DNS 客户端缓存
ProxyState       系统代理 / WinHTTP / 环境变量 / 本地代理端口
```

## P0 功能

### 1. 进程

- 列表：PID、名称、CPU%、内存、路径等
- 搜索/过滤：名称、PID、路径、命令行
- 子进程：树形展开/折叠；列表 / 树形可切换
- 排序：CPU、内存（升/降序）；列表全局排序；树形同级排序
- 详情：基本信息 + 网络 + 文件（文件探测就绪后）+ 资源
- 操作：结束进程 / 结束进程树（确认）；复制 PID/路径/命令行（可后置）

### 2. 端口（一等资源）

- **完整端口/连接列表**：协议、本地地址端口、远程、状态、PID、进程名
- **按端口搜索**：如 `8080`、`7890`
- **按进程名搜索**：按占用端口的进程名（或路径片段）过滤
- 可组合过滤：端口 + 进程名 + 协议（TCP/UDP/全部）
- 排序：端口、PID、进程名、状态等
- 选中 → 进程详情；可结束进程（确认）
- 常见代理端口可高亮提示（不限制只显示这些）
- 刷新：遵循全局刷新策略

### 3. 文件/目录 → 进程

- 输入或选择路径，列出持有句柄的进程
- 进详情；可结束进程
- Windows 上可能需管理员；权限不足时明确提示

### 4. DNS 缓存管理

面向代理使用后解析异常等场景：

- **查看** DNS 客户端缓存：主机名、记录类型、地址、TTL（平台能提供则显示）
- **搜索**：按域名 / IP
- **删除单条**（平台支持时）；不支持则 UI 明确「仅支持清空全部」
- **清空全部**：二次确认；失败原因可读（含是否需提权）
- 列表手动刷新；默认不与进程列表同高频自动刷

### 5. 代理排障体检（P0）

独立入口，帮助定位「代理使用中 / 退出后」的异常：

1. **系统代理**：开/关、HTTP/HTTPS/SOCKS 地址与端口  
2. **WinHTTP 代理**（Windows）  
3. **环境变量**：`HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` / `NO_PROXY`（及小写变体）  
4. **常见本地代理端口**是否在监听、被谁占用（复用端口数据）  
5. **DNS 缓存**：入口跳转 + 一键清空（确认）  
6. **体检报告**：红 / 黄 / 绿条目；例如「系统代理指向 `127.0.0.1:7890` 但端口无进程监听」标红  

快捷修复（均需确认）：清空 DNS 缓存、关闭系统代理、重置 WinHTTP（Windows）。

### 6. 刷新

- 可设置自动刷新频率（建议 0.5s–10s）
- 可关闭自动刷新，仅手动（F5 / 按钮）
- 显示上次刷新时间；设置持久化（可后置）
- 文件句柄 / DNS 缓存：默认可与全局不同频或仅手动
- 结束进程 / 修复操作成功后立即刷新相关视图

## P1（随后）

- DNS：本机 DNS 服务器配置只读、hosts 查看、系统解析 vs 指定服务器对比查询
- 代理排障：hosts 可疑行、路由/虚拟网卡摘要、开代理前快照 diff
- 设置持久化、虚拟列表、管理员提权提示
- 文件句柄完整实现
- macOS / Linux 对应 Probe 实现

## Icebox

流量统计、防火墙编辑、进程级 DNS 查询挂钩、抓包、代理内核管理。

---

## 验收（P0）

1. 进程可搜索、按 CPU/内存排序、展开子进程；可结束进程  
2. 端口可浏览全表，可按端口号、进程名搜索，可跳转进程并结束  
3. DNS 缓存可查看、可清空；单条删除在平台支持时可用  
4. 代理排障页能展示系统代理 / WinHTTP / 环境变量 / 本地代理端口，并对「代理残留」标红  
5. 刷新可调频或关闭；危险操作有确认；失败有可读错误
